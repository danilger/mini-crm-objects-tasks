# Как устроена система (для руководителя)

Это небольшая CRM для стройки: есть **объекты** (стройки) и **задачи** по ним.

## Кто что может

**Постановщик** создаёт объекты и задачи, назначает исполнителей, принимает работу или возвращает на доработку. Он видит всё.

**Исполнитель** видит только свои задачи и те объекты, где у него есть задачи. Он может взять задачу в работу и отправить на проверку. Чужие задачи ему недоступны.

## Как движется задача

Новая → В работе → На проверке → Принята.

С проверки постановщик может вернуть задачу **на доработку** (обязательно с комментарием). С доработки исполнитель снова берёт её в работу.

Каждый переход записывается в историю: кто, когда, какой был статус и какой стал, плюс комментарий если он был.

## Как защищены данные

Права проверяются не только в интерфейсе, но и в базе данных. Даже если кто-то отправит запрос напрямую в API, минуя кнопки на экране:

- исполнитель не прочитает и не изменит чужую задачу;
- нельзя перевести задачу в запрещённый статус;
- историю статусов нельзя подделать, изменить или удалить.

Вход только для заранее созданных пользователей: открытой регистрации нет.
